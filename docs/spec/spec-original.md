# mycompany요구사항

## 요구사항

- 회사홈페이지 개발
- 회원관리(admin/user), 제품소개, 게시판, 문의하기 개발

## 상세 요구사항 (도출됨)

### A. 인증 / 회원관리
1. 이메일/비밀번호 회원가입 (`supabase.auth.signUp` + `public.users` 프로필 레코드 생성)
   - 엣지케이스: 이메일/닉네임 중복, 비밀번호 정책 미달, 이메일 인증 미완료, auth.users는 생성됐는데 public.users insert가 실패하는 불일치 상황
2. 로그인/로그아웃 + 세션 자동 복원 (`onAuthStateChange`)
   - 엣지케이스: 잘못된 자격증명 반복 시도, 이메일 미인증 계정 로그인 시도, 세션 만료 중 액션, 다중 탭/기기 동기화
3. 회원 등급 구분 (admin/user) — `public.users.role` 컬럼 기준 권한 분기
   - 엣지케이스: role 값 NULL 처리, 일반 사용자의 관리자 라우트 직접 URL 접근, role 변경 직후 세션 권한 불일치
4. 마이페이지/프로필 관리 (닉네임, 프로필이미지, 자기소개, 지역정보 조회·수정)
   - 엣지케이스: 프로필 이미지 업로드 용량/형식 초과, 닉네임 변경 시 중복 검사, 위치정보(위도/경도) 미입력 표시
5. 보호된 라우트 처리 (비로그인 시 `/login` 리다이렉트, 로그인 후 원래 페이지로 복귀)
   - 엣지케이스: 복귀 대상 페이지가 더 이상 존재하지 않는 경우, 권한 없는 자원 접근 시 403 처리

### B. 홈 / 회사소개
6. 홈 랜딩 페이지 (회사 소개 요약 + 주요 메뉴 진입 배너)
   - 엣지케이스: 데이터 로딩 실패 시 fallback UI, 콘텐츠 없음 상태
7. 회사소개 서브페이지 (개요/연혁/조직도/오시는 길)
   - 엣지케이스: 지도 API 로드 실패, 모바일에서 조직도 가독성, 잘못된 서브경로 접근 시 404

### C. 제품소개
8. 제품 목록 조회 (이미지/이름/요약 + 페이지네이션 또는 무한스크롤)
   - 엣지케이스: 제품이 0개인 경우, 이미지 로드 실패 시 대체 이미지, 정렬 기준 불명확
9. 제품 상세 조회 (`/products/:id`)
   - 엣지케이스: 존재하지 않는 id 접근 시 404, 잘못된 형식의 id 접근

### D. 게시판
10. 게시판 목록(선택) — `boards`에서 `is_active = true` 항목만 카드/리스트로 노출
    - 엣지케이스: 활성 게시판이 0개, 게시판 설명 누락
11. 게시글 목록 조회 — `board_id` 필터 + `.range(from, to)` 페이지네이션
    - 엣지케이스: 게시글이 0개, 마지막 페이지/범위를 초과한 페이지 요청, 존재하지 않는 board_id 접근
12. 게시글 작성 (로그인 필요, `posts_insert` RLS, 제목 최대 200자)
    - 엣지케이스: 비로그인 사용자의 직접 URL 접근, 제목/내용 글자수 초과, 빈 내용 제출, 작성 중 세션 만료
13. 게시글 상세 조회 (`posts` + `users` join으로 작성자 닉네임/프로필 표시)
    - 엣지케이스: 작성자가 탈퇴(연쇄 삭제로 게시글도 삭제됨)했을 때 표시, 존재하지 않는 게시글 id 접근(404), XSS 방지(내용에 스크립트 삽입 시도 시 escape)
14. 게시글 수정/삭제 (작성자 본인만 가능, `posts_update`/`posts_delete` RLS)
    - 엣지케이스: 타인이 API/URL로 수정·삭제 시도 시 RLS에 의한 차단과 UI 안내, 동시 수정 충돌(낙관적 동시성)

### E. 문의하기
15. 문의 폼 작성 (이름/이메일/제목/내용 입력 + 필수값 검증)
    - 엣지케이스: 이메일 형식 오류, 필수 항목 누락, 같은 내용 연속 제출(중복/스팸 방지)
16. 문의 완료 안내 (제출 성공 시 `/contact/complete`로 이동, 접수 내용 요약 표시)
    - 엣지케이스: 새로고침/뒤로가기로 완료 페이지 직접 접근, 제출 실패 시 에러 메시지와 재시도 동선

### F. 공통 / 관리자 / 기타
17. 공통 레이아웃(Header/Footer) — 로그인 상태에 따라 버튼 분기, 1단계 메뉴, 모바일 햄버거 메뉴
    - 엣지케이스: 로딩 중 메뉴 깜빡임(loading 상태 처리), 모바일 메뉴 열린 상태에서 라우트 이동 시 닫힘 처리
18. 404 Not Found 처리 (정의되지 않은 경로 접근 시 안내 + 홈 버튼)
    - 엣지케이스: 존재했다가 삭제된 리소스 경로(게시글/제품) 접근도 동일 처리, 잘못된 파라미터 형식
19. 관리자 전용 기능 (`role = 'admin'` 사용자 대상 게시판 활성화 관리, 회원/문의 내역 조회 등)
    - 엣지케이스: admin이 자신의 권한을 일반회원으로 낮추는 경우, 동시에 여러 admin이 같은 데이터 수정, 일반 사용자가 관리자 API를 직접 호출
20. 반응형 디자인 / 기본 접근성 (Tailwind `sm` → `md` → `lg`, 키보드 내비게이션, 명도 대비)
    - 엣지케이스: 좁은 화면에서 표/카드 레이아웃 깨짐, 긴 텍스트(닉네임/제목) 줄바꿈 처리, 시스템 다크모드 설정과의 충돌

## 참고: 스키마 변경 필요 사항

- `public.users` 테이블에 `role` 컬럼(varchar 또는 enum, 기본값 `'user'`) 추가 필요
  → admin/user 구분 및 관리자 전용 페이지·기능의 RLS 정책을 적용하기 위한 전제 조건
